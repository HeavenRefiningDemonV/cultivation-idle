## 3) Red-flag checklist

Reject if any role:

- [ ] behaves like a floating software tag
- [ ] behaves like a tavern signboard
- [ ] behaves like a generic P1-02A header with no world-specific logic
- [ ] requires repainting the map
- [ ] becomes too loud for repeated world use
- [ ] blocks map readability
- [ ] forces text into decorative zones
- [ ] implies destructive cleanup

## 4) Approval language

Allowed outcomes only:

- `READY FOR ART GENERATION`
- `HOLD — NOT WORLD-SPECIFIC ENOUGH`
- `HOLD — OVERLAPS P1-02A`
- `HOLD — OVERLAPS STATE FAMILY`
- `HOLD — TOO LOUD / TOO DECORATIVE`
- `HOLD — MAP OWNERSHIP REGRESSION RISK`
