## C) Red-flag checklist (reject on any true item)

- [ ] Variant reads like a scenic picture frame.
- [ ] Variant is too ornate to stretch safely.
- [ ] Variant leans western-fantasy metal frame language.
- [ ] Variant leans sci-fi HUD/chrome language.
- [ ] Variant bakes in text/iconography.
- [ ] Variant is compensating for a layout/code issue rather than role-specific chrome need.
- [ ] Variant duplicates plaque/title-plate responsibilities.
- [ ] Variant would flatten strong screen identity into one generic rectangle.
