## Red-flag checklist

- [ ] Ornament replaces chip/text as primary state meaning.
- [ ] Ornament introduces layout shift when toggled.
- [ ] Ornament reads as giant banner/spectacle for normal recommendation state.
- [ ] Ornament overlaps scenic ownership or looks like screen-local repaint.
- [ ] Ornament collides with plaque/header chrome ownership.
- [ ] Ornament becomes illegible in grayscale or low-saturation modes.
- [ ] Ornament causes badge clutter in dense surfaces.
- [ ] Ornament depends on high motion/FX to remain understandable.
