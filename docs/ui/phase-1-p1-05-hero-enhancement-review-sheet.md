1. Does the target screen prove a real missing-role gap?
2. Is the current scenic owner still primary in all evidence captures?
3. Is the request support-role only (not ownership transfer)?
4. Is the request additive-only?
5. Are High FX / Low FX / Reduced Motion screenshots already available?
6. Is the request avoiding "hero paint" as a fix for layout/truth-surface problems?
7. Is there zero hidden scenic replacement risk?
