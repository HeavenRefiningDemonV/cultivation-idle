## 3) Red-flag checklist

Reject if any role:

- [ ] behaves like a world/building placard
- [ ] behaves like a state stamp
- [ ] behaves like a full frame
- [ ] depends on a center emblem
- [ ] becomes too ornate for repeated use
- [ ] forces text into decorative zones
- [ ] looks like fantasy metal or glossy mobile UI
- [ ] implies destructive cleanup
