# Artifact / Treasure Imprints Future Gate

P5 does not ship a live artifact system. This document reserves the future shape so treasures do not become random loot bloat or a second Forge gear track.

## Runtime Status

- Current status: `future_stub_only`.
- No live random relic drops are allowed in P5.
- No artifact equipment slots, artifact currencies, random treasure loot tables, or live attunement buttons are added in P5.
- Inventory treasure filters may keep showing existing safe inventory categories, but no item should promise a live Artifact Imprint effect without a runtime consumer.

## Future Admission Rule

Every future relic must name:

- Source event: the meaningful event that created the imprint.
- Doctrine: the cultivation pattern or Heart Law family the relic expresses.
- Attunement condition: the concrete threshold that makes it relevant.
- Current role: gate support, cultivation support, economy support, or memory support.
- Sink: the existing loop where the imprint matters.
- Memory line: the short life-summary or Records line it leaves behind.

## Design Limits

- One named relic per major phase is preferred over random spam.
- Relics attach to existing loops: Ruins, Gate Trial, Heart Law, Records, and Prestige memory.
- Relics must not compete with Forge gear as generic stat sticks.
- Relics should explain source, sink, and current relevance before any player-facing visibility.
- No relic content should be visible unless a runtime consumer exists.
