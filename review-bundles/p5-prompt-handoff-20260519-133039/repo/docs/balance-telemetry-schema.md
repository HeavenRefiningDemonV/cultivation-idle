# Balance Telemetry Schema (Section 6.8)

## Scope
Local-only diagnostics telemetry for balance tuning. No upload, no account linkage, no save serialization.

## Canonical owners
- Event schema: `src/services/diagnostics/balanceTelemetrySchema.ts`
- Runtime capture: `src/services/diagnostics/balanceTelemetryService.ts`
- Export/report/KPI logic: `src/services/diagnostics/balanceTelemetryExport.ts`

## Schema version
- `schemaVersion: 1`

## Event families / kinds
- progression: `life_started`, `gate_available`, `breakthrough`, `city_entered`, `content_cap_reached`
- trials: `attempt_started`, `attempt_resolved`, `gate_resolved`
- readiness: `snapshot`
- diagnosis: `computed`
- economy: `currency_earned`, `currency_spent`, `items_gained`, `items_spent`
- support: `bounty_claimed`, `expedition_started`, `expedition_claimed`
- prestige: `performed`, `upgrade_purchased`
- reclaim: `milestone_reached`
- offline: `applied`

## Base metadata fields
Common envelope fields include:
- `eventId`, `emittedAt`, `family`, `name`, `kind`
- life/session context: `lifeId`, `lifeOrdinal`, `sessionKind`, `prestigeCount`
- progression context: `realmIndex`, `realmId`, `substage`, `cityId`, `cityIndex`
- `elapsedMsSinceLifeStart`

## KPI derivation rules
Implemented in `buildBalanceTelemetryReport(...)`:
- Attempts per gate: counted from `trials/attempt_resolved` (single-count rule).
- Win rate by readiness band: `readiness/snapshot` bands paired to trial attempt resolution outcomes.
- Currency source/sink totals: derived only from typed `economy/currency_earned` and `economy/currency_spent`.
- Reclaim milestones: derived from `reclaim/milestone_reached` events.
- Expedition cadence: derived from `support/expedition_started` and `support/expedition_claimed` timestamps.
- Offline aggregates: derived from `offline/applied` fields.

## Commands
- `npm run telemetry:export -- --input <file> [--out-dir <dir>]`
- `npm run telemetry:summary -- --input <file> [--json]`

## Guard rails / non-goals
- Ring buffer is bounded (`maxBalanceEvents`, hard clamp).
- Capture can be disabled (`balanceCaptureEnabled`) with fast no-op append path.
- Telemetry remains runtime-only (not saved into save files).
- Exports run only on explicit user action or CLI invocation.
