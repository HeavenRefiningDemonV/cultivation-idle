# Apothecary Exact Assets

Created by APX-00, Apothecary Exact Asset Intake and Manifest.

This folder contains asset evidence only. Nothing in this folder is imported at runtime by APX-00.

## Folder contract

- `raw/` preserves untouched original image files from the source archive.
- Role folders contain byte-identical normalized copies with stable snake_case names for future APX-01/APX-05 registry work.
- `manifest/` records source names, normalized paths, dimensions, alpha/crop metadata, hashes, roles, and review warnings.

## Runtime cautions

- The approved mockup is not a runtime background.
- The room scenic plate can become the page base only if visual review confirms it has no baked UI text.
- Individual remedy, source, and warning sprites should be used later; atlases are reference-only.
- Future derived crops must preserve raw originals and be generated reproducibly in a later packet.
