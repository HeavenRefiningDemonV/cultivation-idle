# heroes support-art scaffold root (P1-01B)

## Folder purpose
This root is the scaffold landing zone for later-wave hero enhancement support kits.

## Blocked-spec status (P1-05)
Hero enhancement families are blocked until P1-05 trigger conditions are satisfied with screenshot-backed proof.

No live screen integration is allowed from this root in the blocked state.

## What belongs here (allowlist only)

### Cultivation later-wave support parts
- altar base
- ring layers
- glow masks
- aura wisps
- doctrine-side underplates
- optional verse/stability companion support

### Heart Law later-wave support parts
- altar base
- scripture stand / pedestal support
- seal / medallion companions
- circular doctrine overlays
- preview underlays
- resonance-emphasis support parts

## What does not belong here
- replacement hero paintings
- replacement cultivator center art
- replacement Heart Law core logic/truth surfaces
- replacement path portraits
- scenic repaint layers

## Naming examples
- `cultivation_hero_ring_outer_default.png`
- `cultivation_hero_glow_mask_soft_a.png`
- `heartlaw_hero_seal_pedestal_default.png`

## Allowed formats
- Transparent PNG by default
- SVG only for clearly flat emblem/seal geometry when justified
- No JPG

## Packet scope note
This is a scaffold root only in Phase 1 docs/spec packets. Do not add placeholder art files.
