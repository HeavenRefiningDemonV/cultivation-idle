# heroes support-art scaffold root (P1-01B)

## Folder purpose
This root is the scaffold landing zone for later-wave hero enhancement support kits.

## What belongs here
- cultivation altar/ring/glow/aura/seal support layers
- Heart Law altar/seal/pedestal support layers

## What does not belong here
- replacement hero paintings
- replacement cultivator center art
- replacement path portraits

## Naming examples
- `cultivation_hero_ring_outer_default.png`
- `cultivation_hero_glow_mask_soft_a.png`
- `heartlaw_hero_seal_pedestal_default.png`

## Allowed formats
- Transparent PNG by default
- SVG only for clearly flat emblem/seal geometry when justified
- No JPG

## Packet scope note
This is a scaffold root only in P1-01B. Do not add placeholder art files.

## Import gate note
No live screen should import from this root yet.

Preserve-core assets (including `src/assets/ui/book_spines/`) remain untouched.
