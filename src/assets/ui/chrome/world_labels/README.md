# world_labels scaffold root (P1-02B)

## Folder purpose
Dedicated world-facing diegetic label family for building names, district labels, selected-building emphasis, current-city identity, city-arrival identity, and world-only route hints.

## What belongs here
- building label plaques
- selected-building emphasis plates
- district/area label plaques
- current-city identity plates
- city-arrival world banners
- world-only route-hint plaques

## What does not belong here
- generic shared plaque/ribbon/title roles from P1-02A
- state stamp/swash/recommendation families
- non-world headers/breadcrumbs
- map repaint assets or scenic replacements

- `ui_label_building_world_default_m.png`
- `ui_plate_building_selected_world_default_m.png`
- `ui_label_district_world_default_l.png`
- `ui_plate_city_current_world_default_l.png`
- `ui_banner_city_arrival_world_default_l.png`
- `ui_hint_route_world_default_s.png`

## Relation to P1-02A
This root is a world-specific sibling family to P1-02A shared plaques; it does not replace generic shared plaque/ribbon/title usage.

## Relation to World Hub
Assets here are world-facing and diegetic; they must preserve the world map as hero plane.
