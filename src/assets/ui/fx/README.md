# fx support-art scaffold root (P1-01B)

## Folder purpose
This root is the scaffold landing zone for shared support FX parts.

## What belongs here
- mist
- dust
- glints
- embers
- halos
- seal pulses
- brush swashes

## What does not belong here
- readable truth carriers
- neon HUD effects
- giant full-screen spectacle assets

## Naming examples
- `mist_fx_soft_loop_a.png`
- `embers_fx_low_density_b.png`
- `seal_pulse_fx_ring_soft_a.png`

## Allowed formats
- Transparent PNG (atlas-friendly)
- No JPG
