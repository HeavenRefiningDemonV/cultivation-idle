# Reuse Map

This folder records **real existing assets** that can be reused for the new UI language.

## What belongs here
- Metadata-only reuse entries pointing to real `sourcePath` files already in the repo.
- Honest notes about fit quality and limitations.

## What does not belong here
- Copied/duplicated image files.
- Guessed paths that do not exist.
- Claims that a partial-fit asset is final-perfect.

## Naming expectations
- Use stable `ui.reuse.*` ids and snake_case logical names.
- Keep `expectedPath` aligned to the future canonical `src/assets/ui/**` destination.
